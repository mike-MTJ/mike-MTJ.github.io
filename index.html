Topic: Semantic Html

Tag Name Description
<header> Header Defines a header for an html page/document.
<nav> Navigation Defines a container for navigation links.
<main> Main Defines the main content of an html document.
<Section> Section Defines a section in an html document.
<figure> Figure Defines a container for a figure and its caption.
<figcaption> Figcaption Defines a caption for a figure.
<article> Article Defines an article in an html document.
<Video> Video Defines a container for a video in an html document.

Attributes

Attribute Description
src Specifies the URL of the video/audio source.
controls Define the controls for the video/audio.
autoplay Specifies that the video/audio will start playing as soon as it is ready.
type Specifies the format of the video being displayed.
